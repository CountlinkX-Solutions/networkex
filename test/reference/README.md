# Oracle fixtures

The fixtures under `fixtures/` are generated by the scripts in this directory with the reference
libraries (spaghetti and libpysal) and committed. CI never runs Python: the Elixir and
Rust tests compare against the committed JSON.

```sh
uv venv .venv
uv pip install --python .venv/bin/python -r test/reference/requirements.txt
prlimit --as=3221225472 .venv/bin/python -I test/reference/generate_<name>.py
```

`common.py` holds the JSON conventions (deterministic output, non-finite floats as strings) and
the `meta` block of library versions every fixture carries. A generator never copies library
code: it only runs the libraries to record their results.
